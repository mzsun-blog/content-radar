              연결 상태

              API 키는 공개 페이지에 넣지 않고 중계 서버(Cloudflare Worker)의 비밀값으로만 보관합니다. 키를 바꾸려면 Cloudflare 대시보드 → 이 Worker → 설정 → 변수 및 비밀에서 수정하세요.

              중계 서버

                키 발급 위치

                퀴즈 자동 수집

                Worker가 10분마다 확인해서 아래 시간대에서 정해진 분만큼 지난 시각에 토스 행운퀴즈·캐시워크 돈버는퀴즈 정답을 수집해 원본에 쌓습니다. 정리본은 이 시간대를 기준으로 나뉩니다.

                같은 글은 다시 읽지 않아서 새 글이 없으면 AI 호출 비용이 들지 않습니다. 자동 수집에는 Worker의 FIREBASE_SA_JSON 비밀값과 Cron 트리거가 필요합니다(SETUP.md 참고).

                지침 · 데이터 가져오기

                작성 지침과 컨설팅 지침은 공개 페이지에 넣지 않고 내 계정 저장소에만 보관합니다.

                  PC에서 content-radar 폴더를 통째로 고르면 lib/knowledge의 지침 6개와 data 폴더의 기존 기록(프로필·말투·시즌·큐·제외 키워드·작성한 글·전략 리포트)을 한 번에 가져옵니다. API 키 항목은 가져오지 않습니다. 휴대폰에서는 [파일 선택]으로 파일을 골라도 됩니다.
